A.2 Analisis biaya waktu PINDAH n, KIRIM n, dan CARI
----------------------------------------------------
Notasi: |A| = jumlah paket di A, |B| = jumlah paket di B,
        n = parameter perintah.

Operasi dasar:
  - enqueue : O(1). Memakai tail, hanya mengubah tail->next dan tail.
  - dequeue : O(1). Memakai head, hanya mengubah head (dan tail bila kosong).

PINDAH n : O(|A| + n)
  - Validasi memanggil nbList(A) untuk memastikan n <= isi A. nbList menelusuri
    seluruh A, sehingga biayanya O(|A|).
  - Pemindahan dilakukan n kali, tiap kali 1 dequeue(A) + 1 enqueue(B), yaitu
    O(1) per paket, jadi O(n) seluruhnya.
  - Karena n <= |A|, total O(|A|). Bila nbList diganti penghitung jumlah yang
    disimpan di struct Queue, validasi menjadi O(1) dan PINDAH n menjadi O(n).

KIRIM n : O(|B| + n)
  - Validasi nbList(B) berbiaya O(|B|).
  - n kali dequeue(B), cetak, perbarui statistik, dan dealokasi (delete),
    semuanya O(1) per paket, jadi O(n).
  - Karena n <= |B|, total O(|B|).

CARI kode : O(|A| + |B|) pada kasus terburuk
  - findElm menelusuri A secara linear; bila tidak ketemu, dilanjutkan ke B.
  - Setelah ketemu, posisi dihitung dengan menelusuri antrean dari depan,
    biayanya O(posisi).
  - Kasus terburuk adalah kode yang tidak ada (kedua antrean ditelusuri
    penuh). Kasus terbaik O(1) bila kode ada di paling depan A.

Tambahan: MASUK berbiaya O(|A| + |B|) karena harus memeriksa keunikan kode di
kedua antrean dengan findElm; enqueue-nya sendiri O(1).

Tabel ringkas:
  +-----------+------------------+-------------------------------------------+
  | Operasi   | Biaya            | Sumber biaya                              |
  +-----------+------------------+-------------------------------------------+
  | enqueue   | O(1)             | akses tail                                |
  | dequeue   | O(1)             | akses head                                |
  | PINDAH n  | O(|A| + n)       | nbList(A) + n kali (dequeue + enqueue)    |
  | KIRIM n   | O(|B| + n)       | nbList(B) + n kali (dequeue + delete)     |
  | CARI      | O(|A| + |B|)     | pencarian linear di A lalu B              |
  | MASUK     | O(|A| + |B|)     | cek kode unik di A dan B                  |
  +-----------+------------------+-------------------------------------------+

A.3 Menelusuri satu perpindahan node
------------------------------------
Kasus: PINDAH 1 saat A = P17 -> P28 -> P36 dan B kosong.

Keadaan awal:
  A.head = &P17, A.tail = &P36, B.head = B.tail = nullptr.

Langkah 1 - dequeue(A):
  - P = A.head              (P menunjuk node P17)
  - A.head = P->next        (A.head menunjuk node P28)
  - A.head tidak nullptr, jadi A.tail tidak berubah (tetap &P36)
  - P->next = nullptr       (node P17 putus dari P28)
  - P dikembalikan. Node P17 sekarang tidak tersambung ke queue mana pun.

Langkah 2 - enqueue(B, P):
  - P tidak nullptr dan P->next == nullptr, sehingga lolos pemeriksaan.
  - B kosong, jadi B.head = P dan B.tail = P.

Keadaan akhir:
  A = P28 -> P36, B = P17.
  Tidak ada new maupun delete. Alamat node P17 tidak berubah; ini dibuktikan
  perintah ALAMAT (alamat sama sebelum dan sesudah PINDAH, tetapi
  fFindElm(A) berubah dari "ya" menjadi "tidak" dan fFindElm(B) dari "tidak"
  menjadi "ya").

Kasus node terakhir A:
  Bila node yang dipindah adalah satu-satunya node di A, maka pada dequeue
  A.head menjadi nullptr, lalu A.tail juga diisi nullptr. Dengan begitu A
  kembali ke keadaan kosong baku (head = tail = nullptr).

A.4 Pencegahan kebocoran memori
-------------------------------
  1. Setiap new (di alokasi) berpasangan dengan tepat satu delete (di
     dealokasi). Pembebasan terjadi pada KIRIM, BERSIHKAN, SELESAI, dan akhir
     input (delAll dipanggil lagi di akhir main, aman dipanggil berulang).
  2. PINDAH tidak membuat dan tidak menghapus node; ia hanya menyambung ulang
     pointer. Jumlah node total (|A| + |B|) tidak berubah.
  3. Bila enqueue gagal setelah alokasi (pada MASUK), node langsung
     dibebaskan sebelum perintah ditolak.
  4. Seluruh validasi (n positif, n <= isi antrean sumber, berat, panjang
     kode, keunikan kode) dilakukan SEBELUM struktur diubah. Tidak ada
     pemrosesan sebagian, sehingga tidak ada node yang tertinggal di
     keadaan setengah jadi.
  5. delAll membebaskan node satu per satu lewat dequeue + dealokasi sehingga
     tidak ada node yang terlewat.
  6. Dibuktikan dengan LeakSanitizer: tidak ada kebocoran, termasuk setelah
     BERSIHKAN dan SELESAI dengan sisa node di antrean.

A.5 Pencegahan pelepasan node dua kali (double delete)
------------------------------------------------------
  1. dealokasi(adrPaket& P) menerima pointer secara by reference dan mengisi
     P = nullptr setelah delete. Pemanggilan dealokasi kedua pada variabel
     yang sama hanya menemukan nullptr dan tidak melakukan apa-apa.
  2. Node hanya di-delete setelah dilepas oleh dequeue, sehingga pada saat
     dibebaskan node tidak lagi bisa dijangkau dari head atau tail mana pun.
     KIRIM dan delAll selalu memakai urutan dequeue lalu dealokasi.
  3. Data (kode dan berat) dicatat ke statistik SEBELUM dealokasi, sehingga
     alamat yang sudah dibebaskan tidak pernah diakses (tidak ada
     use-after-free).
  4. dequeue mengisi next = nullptr dan enqueue menolak node yang next-nya
     bukan nullptr atau yang sudah menjadi tail. Dengan begitu satu node
     hanya menjadi anggota satu queue pada satu waktu. Hal ini diperiksa oleh
     perintah CEK (head/tail konsisten, tail->next = nullptr, dan tidak ada
     node yang berada di A dan B sekaligus).

B.2 Analisis biaya waktu satu enqueue, satu dequeue, dan satu batch k
---------------------------------------------------------------------
Notasi: N = kapasitas buffer (6), k = ukuran batch (1..6).

VERSI 1 - Array geser
  - enqueue : O(1). Tulis di indeks tail+1.
  - dequeue : O(N). Setelah mengambil data indeks 0, semua data sesudahnya
              (sampai N-1 rekaman) digeser satu tempat ke kiri agar head
              tetap 0.
  - batch TULIS k : O(k)      (k kali enqueue, masing-masing O(1))
  - batch AMBIL k : O(k * N)  (k kali dequeue, masing-masing O(N))

VERSI 2 - Array dengan pemadatan
  - enqueue : O(1) pada umumnya. Pada saat pemadatan (enqueue butuh ruang
              dan tail sudah di indeks 5 sementara head > 0) biayanya O(N)
              karena seluruh data aktif digeser ke awal.
  - dequeue : O(1). Hanya memajukan head.
  - batch TULIS k : O(k + N). Pemadatan paling banyak terjadi satu kali per
                    batch, karena ruang batch sudah divalidasi dan setelah
                    pemadatan tail turun ke posisi n sehingga sisa penulisan
                    muat tanpa pemadatan lagi.
  - batch AMBIL k : O(k)

VERSI 3 - Circular queue
  - enqueue : O(1). Posisi tulis (head + count) mod 6.
  - dequeue : O(1). head = (head + 1) mod 6.
  - batch TULIS k : O(k)
  - batch AMBIL k : O(k)

Tabel ringkas:
  +-----------------+-----------+-------------+---------------+-------------+
  | Versi           | 1 enqueue | 1 dequeue   | TULIS k       | AMBIL k     |
  +-----------------+-----------+-------------+---------------+-------------+
  | 1. Array geser  | O(1)      | O(N)        | O(k)          | O(k * N)    |
  | 2. Pemadatan    | O(1)/O(N) | O(1)        | O(k + N)      | O(k)        |
  | 3. Circular     | O(1)      | O(1)        | O(k)          | O(k)        |
  +-----------------+-----------+-------------+---------------+-------------+
  (versi 2, enqueue: O(N) hanya saat pemadatan)

Karena N = 6 adalah konstanta, secara formal semuanya O(1). Perbedaannya baru
terasa bila kapasitas diperbesar, dan sudah terlihat pada penghitung
pergeseran (9, 4, 0).

#ifndef PAKET_H
#define PAKET_H

#include <string>

// Node paket: sekaligus elemen singly linked list.
struct Paket {
    std::string kode;   // satu kata, 1-10 karakter
    int berat;          // 1-5000 gram
    Paket* next;        // penunjuk ke node berikutnya
};
typedef Paket* adrPaket;

// Queue = singly linked list dengan head (depan) dan tail (belakang).
struct Queue {
    adrPaket head;
    adrPaket tail;
};

// ---- operasi wajib ----
void     createQueue(Queue& Q);                          // head = tail = nullptr
bool     isEmptyQueue(const Queue& Q);                   // true jika kosong
adrPaket alokasi(const std::string& kode, int berat);    // nullptr jika gagal
void     dealokasi(adrPaket& P);                         // delete, lalu P = nullptr
bool     enqueue(Queue& Q, adrPaket P);                  // sambung node ke belakang
adrPaket dequeue(Queue& Q);                              // lepas node depan (tanpa delete)
adrPaket findElm(const Queue& Q, const std::string& kode);   // cari berdasar kode
bool     fFindElm(const Queue& Q, adrPaket P);           // cari berdasar ALAMAT node
int      nbList(const Queue& Q);                         // jumlah node
void     printInfo(const Queue& Q);                      // cetak dari depan
void     delAll(Queue& Q);                               // bebaskan semua node

// ---- fungsi bantu ----
int      posisi(const Queue& Q, adrPaket P);             // posisi mulai 1, 0 jika tidak ada
long     totalBerat(const Queue& Q);                     // jumlah berat seluruh node

// Nama: Adhwa' Zahra Prasesti  NIM: 109102500002
// File : paket.cpp  (implementasi ADT)
#include "paket.h"
#include <iostream>
#include <new>

void createQueue(Queue& Q) {
    Q.head = nullptr;
    Q.tail = nullptr;
}

bool isEmptyQueue(const Queue& Q) {
    return Q.head == nullptr;
}

adrPaket alokasi(const std::string& kode, int berat) {
    adrPaket P = new (std::nothrow) Paket;   // tidak melempar exception
    if (P != nullptr) {
        P->kode = kode;
        P->berat = berat;
        P->next = nullptr;                   // node baru tidak tersambung ke mana pun
    }
    return P;
}

void dealokasi(adrPaket& P) {
    if (P != nullptr) {
        delete P;
        P = nullptr;                         // cegah pemakaian / delete kedua
    }
}

// Menyambung node yang SUDAH dialokasikan ke belakang queue. O(1).
bool enqueue(Queue& Q, adrPaket P) {
    if (P == nullptr) return false;          // tidak ada node
    if (P->next != nullptr) return false;    // node masih tersambung ke list lain
    if (Q.tail == P) return false;           // node yang sama sudah di belakang
    if (isEmptyQueue(Q)) {
        Q.head = P;
        Q.tail = P;
    } else {
        Q.tail->next = P;
        Q.tail = P;
    }
    return true;
}

// Melepas node depan TANPA delete. next node lepas = nullptr. O(1).
adrPaket dequeue(Queue& Q) {
    if (isEmptyQueue(Q)) return nullptr;
    adrPaket P = Q.head;
    Q.head = P->next;
    if (Q.head == nullptr) {
        Q.tail = nullptr;                    // queue menjadi kosong: head = tail = nullptr
    }
    P->next = nullptr;                       // node lepas total dari queue
    return P;
}

adrPaket findElm(const Queue& Q, const std::string& kode) {
    for (adrPaket P = Q.head; P != nullptr; P = P->next) {
        if (P->kode == kode) return P;
    }
    return nullptr;
}

// Keanggotaan berdasarkan alamat (bukan isi): dipakai untuk membuktikan
// bahwa alamat node tetap, tetapi keanggotaan queue berubah setelah PINDAH.
bool fFindElm(const Queue& Q, adrPaket P) {
    if (P == nullptr) return false;
    for (adrPaket C = Q.head; C != nullptr; C = C->next) {
        if (C == P) return true;
    }
    return false;
}

int nbList(const Queue& Q) {
    int n = 0;
    for (adrPaket P = Q.head; P != nullptr; P = P->next) ++n;
    return n;
}

void printInfo(const Queue& Q) {
    if (isEmptyQueue(Q)) {
        std::cout << "(kosong)";
        return;
    }
    for (adrPaket P = Q.head; P != nullptr; P = P->next) {
        std::cout << P->kode << "(" << P->berat << "g)";
        if (P->next != nullptr) std::cout << " -> ";
    }
}

void delAll(Queue& Q) {
    while (!isEmptyQueue(Q)) {
        adrPaket P = dequeue(Q);
        dealokasi(P);
    }
}

int posisi(const Queue& Q, adrPaket P) {
    int pos = 1;
    for (adrPaket C = Q.head; C != nullptr; C = C->next, ++pos) {
        if (C == P) return pos;
    }
    return 0;
}

long totalBerat(const Queue& Q) {
    long t = 0;
    for (adrPaket P = Q.head; P != nullptr; P = P->next) t += P->berat;
    return t;
}

bool cekInvarian(const Queue& Q) {
    if (Q.head == nullptr) return Q.tail == nullptr;     // kosong: head = tail = nullptr
    if (Q.tail == nullptr) return false;
    adrPaket P = Q.head;
    int langkah = 0;
    while (P->next != nullptr) {
        P = P->next;
        if (++langkah > 1000000) return false;           // jaga-jaga siklus
    }
    return P == Q.tail && Q.tail->next == nullptr;       // tail = node terakhir
}

// Memecah baris menjadi token. Mengembalikan jumlah token sebenarnya.
int splitTokens(const std::string& line, std::string tok[], int maxTok) {
    std::istringstream iss(line);
    std::string t;
    int n = 0;
    while (iss >> t) {
        if (n < maxTok) tok[n] = t;
        ++n;
    }
    return n;
}

// Membaca bilangan bulat ketat (hanya [+-]digit). Nilai sangat besar dijenuhkan.
bool parseInt(const std::string& s, long& out) {
    if (s.empty()) return false;
    std::size_t i = 0;
    bool neg = false;
    if (s[0] == '+' || s[0] == '-') { neg = (s[0] == '-'); i = 1; }
    if (i >= s.size()) return false;
    long v = 0;
    int digits = 0;
    for (; i < s.size(); ++i) {
        if (!std::isdigit(static_cast<unsigned char>(s[i]))) return false;
        if (v == 0 && s[i] == '0') continue;          // abaikan nol di depan
        if (digits < 9) v = v * 10 + (s[i] - '0');
        ++digits;
    }
    if (digits > 9) v = 1000000000L;
    out = neg ? -v : v;
    return true;
}

void cmdMasuk(Queue& A, const Queue& B, const std::string tok[], int n) {
    if (n != 3) { std::cout << "DITOLAK: format MASUK kode berat\n"; return; }
    const std::string& kode = tok[1];
    if (kode.size() < 1 || kode.size() > 10) {
        std::cout << "DITOLAK: kode harus 1-10 karakter\n"; return;
    }
    long berat;
    if (!parseInt(tok[2], berat) || berat < 1 || berat > 5000) {
        std::cout << "DITOLAK: berat harus bilangan bulat 1-5000 gram\n"; return;
    }
    if (findElm(A, kode) != nullptr) {
        std::cout << "DITOLAK: kode " << kode << " masih aktif di antrean A\n"; return;
    }
    if (findElm(B, kode) != nullptr) {
        std::cout << "DITOLAK: kode " << kode << " masih aktif di antrean B\n"; return;
    }
    adrPaket P = alokasi(kode, static_cast<int>(berat));
    if (P == nullptr) { std::cout << "DITOLAK: alokasi memori gagal\n"; return; }
    if (!enqueue(A, P)) {
        dealokasi(P);                                  // jangan bocor
        std::cout << "DITOLAK: node gagal disambung ke A\n"; return;
    }
    std::cout << "MASUK berhasil: " << kode << " (" << berat << " gram) di belakang A\n";
}

void cmdPindah(Queue& A, Queue& B, const std::string tok[], int n) {
    if (n != 2) { std::cout << "DITOLAK: format PINDAH n\n"; return; }
    long k;
    if (!parseInt(tok[1], k) || k <= 0) {
        std::cout << "DITOLAK: n harus bilangan bulat positif\n"; return;
    }
    int tersedia = nbList(A);
    if (k > tersedia) {
        std::cout << "DITOLAK: PINDAH " << k << " melebihi isi A (A hanya berisi "
                  << tersedia << " paket)\n";
        return;
    }
    std::cout << "PINDAH berhasil: " << k << " paket A -> B:";
    for (long i = 0; i < k; ++i) {
        adrPaket P = dequeue(A);      // lepas dari A (alamat node tidak berubah)
        enqueue(B, P);                // sambung ke belakang B (tidak ada new/delete)
        std::cout << (i == 0 ? " " : ", ") << P->kode;
    }
    std::cout << "\n";
}

void cmdKirim(Queue& B, Statistik& st, const std::string tok[], int n) {
    if (n != 2) { std::cout << "DITOLAK: format KIRIM n\n"; return; }
    long k;
    if (!parseInt(tok[1], k) || k <= 0) {
        std::cout << "DITOLAK: n harus bilangan bulat positif\n"; return;
    }
    int tersedia = nbList(B);
    if (k > tersedia) {
        std::cout << "DITOLAK: KIRIM " << k << " melebihi isi B (B hanya berisi "
                  << tersedia << " paket)\n";
        return;
    }
    long gram = 0;
    for (long i = 0; i < k; ++i) {
        adrPaket P = dequeue(B);
        std::cout << "Dikirim: " << P->kode << " (" << P->berat << " gram)\n";
        st.jumlah += 1;
        st.berat  += P->berat;
        gram      += P->berat;
        dealokasi(P);                 // data dicatat dulu, baru node dibebaskan
    }
    std::cout << "KIRIM berhasil: " << k << " paket, " << gram << " gram. "
              << "Total terkirim: " << st.jumlah << " paket, " << st.berat << " gram\n";
}

void cmdCari(const Queue& A, const Queue& B, const std::string tok[], int n) {
    if (n != 2) { std::cout << "DITOLAK: format CARI kode\n"; return; }
    adrPaket P = findElm(A, tok[1]);
    char lok = 'A';
    const Queue* Q = &A;
    if (P == nullptr) { P = findElm(B, tok[1]); lok = 'B'; Q = &B; }
    if (P == nullptr) { std::cout << "TIDAK DITEMUKAN\n"; return; }
    std::cout << "Ditemukan: " << P->kode << " di " << lok << ", posisi "
              << posisi(*Q, P) << ", berat " << P->berat << " gram\n";
}

    for (adrPaket P = A.head; P != nullptr && ok; P = P->next)
        if (fFindElm(B, P)) ok = false;

    std::string line;

        std::string tok[MAXTOK];
        int n = splitTokens(line, tok, MAXTOK);
        if (n == 0) continue;
        if (tok[0][0] == '#') {                       // baris komentar
            if (echo) std::cout << line << "\n";
            continue;
        }
        if (echo) std::cout << "> " << line << "\n";

        std::string cmd = tok[0];
        for (std::size_t i = 0; i < cmd.size(); ++i)
            cmd[i] = static_cast<char>(std::toupper(static_cast<unsigned char>(cmd[i])));

        if      (cmd == "MASUK")     cmdMasuk(A, B, tok, n);
        else if (cmd == "PINDAH")    cmdPindah(A, B, tok, n);
        else if (cmd == "KIRIM")     cmdKirim(B, st, tok, n);
        else if (cmd == "CARI")      cmdCari(A, B, tok, n);
        else if (cmd == "ALAMAT")    cmdAlamat(A, B, tok, n);
        else if (cmd == "LIHAT")     cmdLihat(A, B);
        else if (cmd == "REKAP")     cmdRekap(A, B, st);
        else if (cmd == "BERSIHKAN") cmdBersihkan(A, B);
        else if (cmd == "CEK")       cmdCek(A, B);
        else if (cmd == "SELESAI") {
            std::cout << "SELESAI: " << (nbList(A) + nbList(B))
                      << " node sisa dibebaskan. Program berakhir.\n";
            break;
        }
        else std::cout << "DITOLAK: perintah tidak dikenal\n";
    }
    delAll(A);   // aman dipanggil lagi (juga bila input berakhir tanpa SELESAI)
    delAll(B);
    return 0;
}

}

bool enqueue(Buffer& B, int nilai) {
    if (B.tail == KAPASITAS - 1) return false;            // penuh (head selalu 0)
    if (B.head == -1) { B.head = 0; B.tail = 0; }         // dari kosong
    else              { B.tail++; }
    B.data[B.tail].nomor = B.nextNo++;
    B.data[B.tail].nilai = nilai;
    return true;
}

bool dequeue(Buffer& B, Rekaman& hasil) {
    if (B.head == -1) return false;
    hasil = B.data[0];
    for (int i = 1; i <= B.tail; ++i) {                   // geser tiap data 1 tempat ke kiri
        B.data[i - 1] = B.data[i];
        B.geser++;                                        // 1 rekaman dipindahkan = 1 hitungan
    }
    if (B.tail == 0) { B.head = -1; B.tail = -1; }        // menjadi kosong
    else             { B.tail--; }
    return true;
}

// Data aktif digeser ke awal HANYA jika enqueue butuh ruang dan tail sudah di indeks 5.

void createBuffer(Buffer& B) {

    B.nextNo = 1; B.geser = 0;
}
void kosongkan(Buffer& B) { B.head = -1; B.tail = -1; }

int  jumlah(const Buffer& B)      { return (B.head == -1) ? 0 : B.tail - B.head + 1; }
int  ruangKosong(const Buffer& B) { return KAPASITAS - jumlah(B); }

bool enqueue(Buffer& B, int nilai) {
    if (B.head == -1) {                                   // dari kosong
        B.head = 0; B.tail = 0;
    } else if (B.tail == KAPASITAS - 1) {                 // ujung kanan tercapai
        if (B.head == 0) return false;                    // benar-benar penuh
        int n = jumlah(B);                                // PEMADATAN: geser data aktif ke awal
        for (int i = 0; i < n; ++i) {
            B.data[i] = B.data[B.head + i];
            B.geser++;                                    // 1 rekaman dipindahkan = 1 hitungan
        }
        B.head = 0;
        B.tail = n;                                       // posisi tulis = n (tail baru)
    } else {
        B.tail++;
    }
    B.data[B.tail].nomor = B.nextNo++;
    B.data[B.tail].nilai = nilai;
    return true;
}

bool dequeue(Buffer& B, Rekaman& hasil) {
    if (B.head == -1) return false;
    hasil = B.data[B.head];
    if (B.head == B.tail) { B.head = -1; B.tail = -1; }   // menjadi kosong
    else                  { B.head++; }                   // hanya memajukan head
    return true;
}

void createBuffer(Buffer& B) {
    B.head = 0; B.count = 0;
    B.nextNo = 1; B.geser = 0;
}
void kosongkan(Buffer& B) { B.head = 0; B.count = 0; }

int  ruangKosong(const Buffer& B) { return KAPASITAS - B.count; }

bool enqueue(Buffer& B, int nilai) {
    if (B.count == KAPASITAS) return false;
    int tulis = (B.head + B.count) % KAPASITAS;           // posisi tulis dihitung, bukan disimpan
    B.data[tulis].nomor = B.nextNo++;
    B.data[tulis].nilai = nilai;
    B.count++;
    return true;
}

bool dequeue(Buffer& B, Rekaman& hasil) {
    if (B.count == 0) return false;
    hasil = B.data[B.head];
    B.head = (B.head + 1) % KAPASITAS;
    B.count--;
    if (B.count == 0) B.head = 0;                         // keadaan kosong: head = count = 0
    return true;
}

Rekaman elemenKe(const Buffer& B, int i) { return B.data[(B.head + i) % KAPASITAS]; }
int  nomorBerikut(const Buffer& B) { return B.nextNo; }
long totalGeser(const Buffer& B)   { return B.geser; }    // selalu 0

    std::cout << "Fisik:";
    for (int i = 0; i < KAPASITAS; ++i) {
        std::cout << " [" << i << "]=";
        int jarak = (i - B.head + KAPASITAS) % KAPASITAS; // jarak dari head searah jarum jam
        if (jarak < B.count)
            std::cout << B.data[i].nomor << ":" << B.data[i].nilai;
        else std::cout << "kosong";
    }
    std::cout << "\nPenanda: head = " << B.head << ", count = " << B.count;

int splitTokens(const std::string& line, std::string tok[], int maxTok) {
    std::istringstream iss(line);
    std::string t;
    int n = 0;
    while (iss >> t) {
        if (n < maxTok) tok[n] = t;
        ++n;
    }
    return n;
}

bool parseInt(const std::string& s, long& out) {
    if (s.empty()) return false;
    std::size_t i = 0;
    bool neg = false;
    if (s[0] == '+' || s[0] == '-') { neg = (s[0] == '-'); i = 1; }
    if (i >= s.size()) return false;
    long v = 0;
    int digits = 0;
    for (; i < s.size(); ++i) {
        if (!std::isdigit(static_cast<unsigned char>(s[i]))) return false;
        if (v == 0 && s[i] == '0') continue;
        if (digits < 9) v = v * 10 + (s[i] - '0');
        ++digits;
    }
    if (digits > 9) v = 1000000000L;
    out = neg ? -v : v;
    return true;
}

void cmdTulis(Buffer& B, const std::string tok[], int n) {
    if (n < 2) { std::cout << "DITOLAK: format TULIS k v1 ... vk\n"; return; }
    long k;
    if (!parseInt(tok[1], k) || k < 1 || k > KAPASITAS) {
        std::cout << "DITOLAK: k harus bilangan bulat 1-" << KAPASITAS << "\n"; return;
    }
    if (n != k + 2) {
        std::cout << "DITOLAK: jumlah nilai harus tepat k = " << k << " (diberikan " << (n - 2) << ")\n";
        return;
    }
    int nilai[KAPASITAS];
    for (long i = 0; i < k; ++i) {                        // validasi SELURUH batch dahulu
        long v;
        if (!parseInt(tok[2 + i], v) || v < NILAI_MIN || v > NILAI_MAX) {
            std::cout << "DITOLAK: nilai '" << tok[2 + i] << "' di luar rentang "
                      << NILAI_MIN << ".." << NILAI_MAX << " atau bukan bilangan bulat\n";
            return;
        }
        nilai[i] = static_cast<int>(v);
    }
    if (ruangKosong(B) < k) {
        std::cout << "DITOLAK: ruang kosong hanya " << ruangKosong(B) << ", diminta " << k << "\n";
        return;
    }
    std::cout << "TULIS berhasil:";
    for (long i = 0; i < k; ++i) {                        // baru sekarang antrean diubah
        int no = nomorBerikut(B);

    std::cout << "\n";
}

    std::cout << "\n";
    printFisik(B);
    std::cout << "Nomor berikutnya: " << nomorBerikut(B) << "\n";
    std::cout << "Total pergeseran: " << totalGeser(B) << " rekaman\n";
}

void cmdRingkas(const Buffer& B) {
    int c = jumlah(B);
    std::cout << "RINGKAS: jumlah " << c;
    if (c == 0) {
        std::cout << "; total 0; minimum TIDAK ADA; maksimum TIDAK ADA; rata-rata TIDAK ADA\n";
        return;
    }
    long total = 0;
    int mn = elemenKe(B, 0).nilai, mx = mn;
    for (int i = 0; i < c; ++i) {                         // hanya membaca, queue tidak berubah
        int v = elemenKe(B, i).nilai;
        total += v;
        if (v < mn) mn = v;
        if (v > mx) mx = v;
    }
    std::cout << "; total " << total << "; minimum " << mn << "; maksimum " << mx
              << "; rata-rata " << std::fixed << std::setprecision(2)
              << static_cast<double>(total) / c << "\n";
    std::cout.unsetf(std::ios::floatfield);
}

} // namespace

int main(int argc, char* argv[]) {
    bool echo = false;
    for (int i = 1; i < argc; ++i)
        if (std::string(argv[i]) == "--echo") echo = true;

    Buffer B;
    createBuffer(B);

    std::cout << "=== Buffer Hasil Ukur (kapasitas " << KAPASITAS << ") - " << namaVersi() << " ===\n"
              << "Perintah: TULIS k v1..vk | AMBIL k | LIHAT | RINGKAS | KOSONGKAN | SELESAI\n";

    std::string line;
    while (std::getline(std::cin, line)) {
        if (!line.empty() && line.back() == '\r') line.pop_back();
        std::string tok[MAXTOK];
        int n = splitTokens(line, tok, MAXTOK);
        if (n == 0) continue;
        if (tok[0][0] == '#') { if (echo) std::cout << line << "\n"; continue; }
        if (echo) std::cout << "> " << line << "\n";

        std::string cmd = tok[0];
        for (std::size_t i = 0; i < cmd.size(); ++i)
            cmd[i] = static_cast<char>(std::toupper(static_cast<unsigned char>(cmd[i])));

        if      (cmd == "TULIS")     cmdTulis(B, tok, n);
        else if (cmd == "AMBIL")     cmdAmbil(B, tok, n);
        else if (cmd == "LIHAT")     cmdLihat(B);
        else if (cmd == "RINGKAS")   cmdRingkas(B);
        else if (cmd == "KOSONGKAN") { kosongkan(B); std::cout << "KOSONGKAN: buffer dikosongkan (nomor urut & penghitung pergeseran dipertahankan)\n"; }
        else if (cmd == "SELESAI")   { std::cout << "SELESAI. Program berakhir.\n"; break; }
        else std::cout << "DITOLAK: perintah tidak dikenal\n";
    }
    return 0;
}

==============================================================================
BAGIAN F. CARA KOMPILASI (Windows PowerShell / g++)
==============================================================================

Soal 1 (masuk ke folder soal1):
    g++ -std=c++17 main.cpp paket.cpp -o paket
    .\paket.exe
    Get-Content uji_soal1.txt | .\paket.exe --echo

Soal 2 (masuk ke folder soal2):
    g++ -std=c++17 -DVERSI=1 main.cpp buffer_v1.cpp -o v1
    g++ -std=c++17 -DVERSI=2 main.cpp buffer_v2.cpp -o v2
    g++ -std=c++17 -DVERSI=3 main.cpp buffer_v3.cpp -o v3
    Get-Content uji_soal2.txt | .\v1.exe --echo
